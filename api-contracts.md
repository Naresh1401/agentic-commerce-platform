# API Contracts

OpenAPI is generated by FastAPI at `GET /openapi.json` and displayed at `GET /docs`.

## Product Search

`GET /products?query=milk&category=dairy&max_results=5`

```json
{{
  "items": [{{"sku": "SKU-MILK-001", "name": "Organic Whole Milk"}}],
  "count": 1
}}
```

## Inventory

`GET /inventory/store_1001/SKU-PASTA-001`

## Cart Update

`POST /cart/{{cart_id}}/update`

## Checkout Session

`POST /checkout/sessions`

Error format:

```json
{{
  "error": {{
    "code": "INVENTORY_NOT_FOUND",
    "message": "Inventory not found for SKU",
    "request_id": "req_demo"
  }}
}}
```
