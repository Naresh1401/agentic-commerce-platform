# Kickoff Cheatsheet

## 1-Minute Intro

I built a mock agentic grocery commerce platform to practice API-first development, MCP-style commerce tools, multi-agent orchestration, partner integrations, payment safety, RAG, RBAC, testing, and observability.

## Questions To Ask The Team

- Which commerce flows should agents own versus delegate?
- What is the approval model for cart, checkout, and payment-sensitive tools?
- Which partner integration contracts are stable and which are negotiated per partner?
- What observability signals define a safe agentic checkout?

## Terms

- MCP: a tool interface pattern for agents to call external capabilities.
- UCP-style: merchant capability and checkout flow structure for agentic commerce demos.
- A2A: agent-to-agent coordination and handoff.
- AP2-style: payment safety pattern using mandates, confirmation, and auditability.
- API orchestration: composing product, price, inventory, coupon, cart, and checkout APIs into one user workflow.
